# Database Management System Labs

Complete record of my Database Management System (DBMS) lab work: DDL/DML commands, table design, joins, subqueries, and lab assignments, organized lab by lab.

**Author:** Ali Raza
**Program:** BS Computer Science, Abasyn University Islamabad
**Course:** Database Management Systems

---

## Topics Covered

- Database & table creation (DDL: `CREATE`, `ALTER`, `DROP`)
- Data manipulation (DML: `INSERT`, `UPDATE`, `DELETE`)
- Querying data (`SELECT`, `WHERE`, `ORDER BY`, `GROUP BY`, `HAVING`)
- Constraints (Primary Key, Foreign Key, `UNIQUE`, `NOT NULL`, `CHECK`, `DEFAULT`)
- Joins (`INNER`, `LEFT`, `RIGHT`, `FULL`)
- Subqueries and aggregate functions
- ER diagram to table mapping and normalization

## How to Run

1. Install a SQL engine (MySQL, PostgreSQL, or SQL Server, whichever the lab uses).
2. Clone this repository:
   ```bash
   git clone https://github.com/ali0-99/Database-Management-System-Labs.git
   cd Database-Management-System-Labs
   ```
3. Open the `.sql` file of any lab in your SQL client and run it.
